# Kata Gilded Rose

## Descripción

Este proyecto contiene una refactorización de la kata Gilded Rose.

La solución utiliza una arquitectura basada en estrategias para separar las
reglas de negocio de cada tipo de objeto.

## Objetivos

- Reducir la complejidad ciclomática.
- Mejorar la mantenibilidad.
- Facilitar la incorporación de nuevos tipos de objetos.
- Garantizar el comportamiento mediante pruebas unitarias.

## Estructura

- gilded_rose.py: lógica principal.
- item_handlers.py: comportamiento de cada tipo de objeto.
- test_gilded_rose.py: pruebas unitarias.
